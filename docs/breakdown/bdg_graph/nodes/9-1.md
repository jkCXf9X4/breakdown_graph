# Review — what is still contested

## Purpose

The maintainer deciding what to trust next uses this layer to separate the
check's guarantees from its blind spots; without it, structural cleanliness is
mistaken for completeness.

---

Review adds two findings the check cannot produce. The first records design
limits and open questions that bound what a clean check licenses
(`docs/DESIGN.md:625-661`). The second records what the committed reference store
does not exercise, so its clean result is not read as broad coverage. Both are
scrutiny of the evidence, not defects in current state, and neither is closed by
widening the check. The layer fails if a finding is restated as state, if a
reviewer treats a known limit as a bug to suppress, or if the two findings are
read as proof rather than as questions routed to work.

Members, in reading order:

1. (Known limits and open questions)[[47-1,breaks_down]] comes first because it
   bounds what a clean check licenses.
2. (Coverage gaps in the reference store)[[48-1,breaks_down]] follows because it
   bounds what the committed example demonstrates.
