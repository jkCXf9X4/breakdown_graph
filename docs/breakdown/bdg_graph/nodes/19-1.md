# Typed links define the component view

## Purpose

The agent browsing a store uses this claim to decide which nodes belong to the
current view; without it, a direction label is read as a membership filter and a
parent, cycle, or back-edge member is dropped.

---

A view is defined by typed tokens, not by a declared layer or traversal
direction. One token, `(TITLE)[[REF,TYPE]]`, on the source node is the authored
edge; in-edges are derived by reversal (`docs/GRAPH.md:49-53`). The view is the
weakly connected component of one anchor, walked both ways, so a node with
several parents appears once at its minimum hop count, and ring 1's child/parent
split is a label only (`docs/GRAPH.md:66-81`). Ring 0 is the anchor and the
canonical order is `(distance, kind_rank, link type, id, version)` with
`child: 0, parent: 1` (`AGENTS.md:67-72`). Cycles, back-edges, and multiple
parents are legal; only a self-loop is refused (`AGENTS.md:91-92`). Membership
follows authored tokens, so the view makes the producing chain traversable and
realizes (Credibility belongs to the producing chain)[[11-1,realizes]]. It is
falsified when a reachable node is missing or membership depends on direction.
