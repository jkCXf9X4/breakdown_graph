# Freshness is opt-in per edge

## Purpose

The maintainer deciding whether an upstream change invalidates a dependent claim
uses this claim to know which edges are tracked; without it, staleness is
assumed automatic and a stale dependent reads as current.

---

Staleness is tracked per edge and only when the source opts in. A propagating
edge is an entry in the source node's `freshness:` map, keyed by the full target
ref, with `propagates: true` and a `pinned` body hash
(`docs/DESIGN.md:143-158`). Freshness is per edge, not per node: one evidence
node can be fresh for one claim and stale for another
(`docs/DESIGN.md:265-272`). The hash strips token lines and the `## Links`
heading, so a token-only edit never invalidates a pin
(`docs/DESIGN.md:274-277`). `bdg stale` lists propagating edges whose target
moved, and `bdg stale --fix` rewrites the pins (`docs/DESIGN.md:157-158`). An edge
without `propagates` is untracked by choice, not broken. The pin records that
upstream text still matches, so the claim realizes
(Credibility belongs to the producing chain)[[11-1, realizes]]. It is falsified
when a changed upstream body leaves a dependent node reading as current with no
pin.
