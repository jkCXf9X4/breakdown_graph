# One store yields many read-only projections

## Purpose

The reader or agent consuming a slice of the store uses this node as the
projection promise; without it, a pack directory is edited as if it were the
store.

---

One store yields many read-only projections, and none is a second source of
truth: views, `bdg pack` output, and `bdg graph` renders are derived and
disposable (`docs/DESIGN.md:28-31`). A reader needs a bounded slice — one view,
one ring range, one fresh-only context — that cannot acquire edits.
`bdg pack REF --out DIR` writes one view flat with an `INDEX.md`, and `--fresh`
writes only fresh bodies plus `STALE.md` and `AGENTS.md`
(`docs/GRAPH.md:175-187`); `bdg graph --format dot|svg` renders it
(`docs/GRAPH.md:194-197`). It realizes
(Large trees need a bounded agent context)[[12-1, realizes]]: a projection is the
bounded slice a session consumes. The promise fails if a projection is
hand-edited or becomes a fact's only home.
