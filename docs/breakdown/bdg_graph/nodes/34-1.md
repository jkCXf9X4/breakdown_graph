# Stale checking is view-scoped

## Purpose

The reviewer deciding whether a propagating edge needs a fix uses this claim to
scope the check to one component; without it, an edge outside the view is either
missed or fixed against the wrong anchor.

---

`bdg stale` reports only propagating edges inside the selected undirected view;
targets outside are skipped. An edge is propagating when its body link carries a
`pinned` hash or a `propagates` entry, not because of its type
(`tests/test_stale.py:85-96`). The comparison uses the target's body hash, so a
title change or a retitled token does not make a dependent stale
(`tests/test_stale.py:112-158`). The view is undirected: a fix reaches a parent
through the anchor's component, and a ref outside it is refused
(`tests/test_stale.py:161-175`). This claim verifies
(Freshness is opt-in per edge)[[23-1,verifies]]: a non-propagating edge is never listed
(`tests/test_stale.py:71-82`). It is falsified if an in-view propagating edge is
skipped, an out-of-view edge is reported, or a non-propagating edge appears.
