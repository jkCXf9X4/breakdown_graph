# Evolution — what might change

## Purpose

The engineer or agent deciding whether a tool gap is worth work uses this group
to see which candidates are open and what they share; without it, a missing
capability is mistaken for a planned change.

---

The evolution layer holds open work, not current state
(`../../src/agent_methods/methods/product-breakdown/guidelines/layer-guide.md:99-117`).
Four candidates are open, all at suggested; none is selected, none has a plan,
and nothing in the group is built. The funnel contract governs how any of them
may move, and each candidate would revise an existing claim rather than add a
product promise.

The funnel has three stages — suggested, selected, implemented — and states the
stage once on the candidate itself. Selection is a scope decision, not
implementation approval: a selected candidate becomes implementable only when a
plan exists, and an implemented candidate is a closed lookup whose plan is
deleted
(`../../src/agent_methods/methods/product-breakdown/guidelines/change-pipeline.md:26-39`,
`../../src/agent_methods/methods/product-breakdown/guidelines/change-pipeline.md:104-113`).
The contract is descriptive, not a second tracker; no row or register repeats a
stage the candidate does not state
(`../../src/agent_methods/methods/product-breakdown/guidelines/change-pipeline.md:90-102`).

Members, in gap order:

1. (Windows symlink support)[[43-1, breaks_down]] opens the candidates because it
   carries the platform-portability gap.
2. (Generic markdown importer)[[44-1, breaks_down]] follows because it carries
   the input-format gap.
3. (Three-way merge between versions)[[45-1, breaks_down]] follows because it
   carries the version-merge gap.
4. (Snapshot list and prune)[[46-1, breaks_down]] closes the order because it
   carries the history-cleanup gap.

- Open: the four work items are suggested; no plan exists and no candidate is
  built.
- Funnel: suggested, selected, implemented; selection needs a plan, and an
  implemented candidate deletes it
  (`../../src/agent_methods/methods/product-breakdown/guidelines/change-pipeline.md:26-39`,
  `../../src/agent_methods/methods/product-breakdown/guidelines/change-pipeline.md:104-113`).
- Shared condition: each names a gap the tool docs leave unbuilt or unmanaged
  (`docs/DEVELOPING.md:402-411`, `docs/CHEATSHEET.md:308-331`), so the work
  would revise a current claim, not introduce a new one.
- Failure: stale if a candidate moves stage or ships without this group and its
  own node changing, or if the contract stops matching the method's funnel.
