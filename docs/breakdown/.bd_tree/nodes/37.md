# Work module owns the single area

`work.py` builds one `<project>/bd_work/` area of relative symlinks and rewrites its three generated files on every build.

- **Symlinks:** every node `.md` in the area is a relative symlink to its `nodes/<ref>.md`, so an edit writes the store directly.
- **Single area:** no `out` means `<project>/bd_work/`; `Store.project_root` maps `.bd_tree` to its parent, and another ref replaces the same directory.
- **Switch:** `_build` unlinks `stale-ref` entries, prunes empty directories, then links every ref in the new view.
- **Generated files:** `INDEX.md`, `REFS.md`, and `AGENTS.md` are regular files with a generated banner; `GENERATED_SET` reserves their names.
- **Inspection and repair:** `_classify` returns `ok`, `missing`, `wrong-target`, `detached`, or `stray`; `_writeback` validates front matter before re-linking.
- **Git context:** `git_context` records branch, short commit, and toplevel for `AGENTS.md`; a missing checkout leaves those fields out.
