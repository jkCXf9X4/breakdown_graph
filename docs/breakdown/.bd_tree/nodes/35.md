# Ops module performs body-preserving structural edits

`ops.py` rewrites only the targeted front-matter block and appends the original body string byte for byte.

- **Init:** `init_store` writes `.bd_tree/nodes/1.md` with id 1, title Root, and empty `contains`.
- **New:** `new_node` takes the next global id, appends it to the parent's effective `contains`, and derives `folder` from `layer`/`group`/`type` when absent.
- **Contain/uncontain:** both edit the effective list; `contain` refuses self, cycles, and duplicates, while `uncontain` writes `contains: []` when empty.
- **Link/unlink:** `link` appends `{to, type}` and pins the target hash when `propagates` is set; `unlink` removes matching edges.
- **Versions:** `fork` copies main and materialises `contains`; `promote` copies a version onto main; `retire_version` deletes a non-main file.
- **Body safety:** `parse_document` keeps `raw_fm` and `body`, and `rewrite_contains` or `rewrite_links` replaces only its own block.
