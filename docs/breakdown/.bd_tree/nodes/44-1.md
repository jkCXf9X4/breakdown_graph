# Detached edits block a switch until writeback

A regular file where a symlink belongs is `detached`, and `_refresh_guard` refuses a rebuild until the file is written back or cleaned.

- **Cause:** an editor that replaces the symlink leaves a regular `.md` file with edited content in the area.
- **Detection:** `_classify` returns `detached` for a regular file and `stray` for an unexpected `.md` outside the generated names.
- **Writeback:** `_writeback` parses the file, requires valid front matter and a matching `id`, then writes the node file and re-links it.
- **Refusal:** invalid front matter or a mismatched id is listed as invalid and not written.
- **Clean:** `--clean` removes the area and rebuilds it from the store, discarding detached edits.
- **Status:** `bd work --status` reports each non-ok path and exits 1 until the area is healthy.
- **Operates:** the work area is a symlink layout (30-1).
