# Front matter stays project-defined

Only four structural keys are built in, so layers, edge types, and status values remain data the project defines.

- **Reserved keys:** `id`, `legacy`, `contains`, and `links`; every other field is arbitrary and preserved on export.
- **Layers:** `layer`, `phase`, `stage`, `audience`, `status`, and `order` are ordinary fields that the tool never interprets.
- **Edge types:** a link `type` is an arbitrary label, never validated against an enum.
- **Opt-in schema:** `bd check --require FIELD` is the escape hatch when a project wants a required field.
- **Presentation:** path templates read any front-matter field, and dot styling selects by `--color-by` and `--shape-by`.
