# Product Breakdown — bd_tree

This is the systems-engineering record for bd_tree. Current state lives in the claim layers (Intent through Operation), open work in Evolution, and dated history in Decisions. Authors and reviewers enter here to find the one leaf that owns a question before changing anything.

Start at `INDEX.md` (or `bd graph`) and open the one leaf that owns the question you have.

Every lower leaf links to the claim above it with a symmetric trace (`Traces to`, `Implements`, `Verifies`, `Operates`, `Changes`), and `bd export dot --view 1-1 --out FILE` renders the chain.

Decisions is a linked set: `bd show 1-1 --links` points to it, and `bd work 10-1` makes it the active node in the same component.
