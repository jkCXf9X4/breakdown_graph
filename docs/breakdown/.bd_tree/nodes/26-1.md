# Freshness is opt-in per edge

A semantic link participates in freshness only when the source node's `freshness:` map names its target with `propagates: true`, and the pin is stored there keyed by the target ref.

- **Pin:** the `freshness:` entry records a SHA-256 hash of the target body, truncated to twelve hex characters, at reconciliation; reserved token lines and the `## Links` heading are stripped first, so token edits do not invalidate it.
- **Per edge:** one evidence node supporting two claims is fresh for one edge and stale for the other; freshness is not a node property.
- **Untracked:** a propagating target with no `pinned` value is reported as untracked until the first reconcile.
- **Opt-in:** ordinary tokens carry semantics without freshness, so projects choose the cost per relationship.
- **Staleness:** `bd stale` compares pins with current target bodies in the same view; `bd reconcile` rewrites them after review.
- **Traces to:** credibility belongs to the producing chain (16-1).
