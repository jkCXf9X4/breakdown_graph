# Freshness is opt-in per edge

A semantic link participates in freshness only when it declares `propagates: true`, and the pin is stored on that edge.

- **Pin:** the edge records a SHA-256 hash of the target body, truncated to twelve hex characters, at reconciliation.
- **Per edge:** one evidence node supporting two claims is fresh for one edge and stale for the other; freshness is not a node property.
- **Untracked:** a propagating edge with no pin is reported as untracked until the first reconcile.
- **Opt-in:** ordinary links carry semantics without freshness, so projects choose the cost per relationship.
- **Staleness:** `bd stale` compares pins with current target bodies in the same view; `bd reconcile` rewrites them after review.
