# Exporter renders read-only projections

`exporter.py` registers `context`, `dot`, and `svg`; `graph.py` registers `graph`. The first three take a `View`, `graph` takes the built graph and an anchor, and each writes an `ExportResult` under `--out`.

- **Registry:** `@exporter(name)` fills `EXPORTERS`; `api.export_view` looks up the name, loads the view, refuses invalid views, and calls the function.
- **Graph projection:** `bd export graph REF --out DIR` runs `export_graph`, which writes each node under its band folder plus a root and per-folder `INDEX.md`.
- **Context projection:** `export_context` writes only fresh nodes, with `STALE.md` and `AGENTS.md`; stale source bodies stay absent.
- **Dot projection:** `export_dot` writes Graphviz with colours and shapes chosen by arbitrary front-matter fields; `export_svg` renders it to SVG.
- **Disposable output:** `_prepare_out` refuses a non-empty directory without `--force` or `--clean`, and nothing is written outside `out`.
- **Placement:** default paths follow the band layout (`layout_paths`); `--path-template` can render `{ref}`, `{id}`, `{version}`, `{name}`, `{slug}`, or any front-matter field, and `path_problem` rejects escapes and non-markdown paths.
- **Implements:** structural links define the view closure (25-1).
