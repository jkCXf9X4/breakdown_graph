# Branch-switch layout repair

Switching branches in one checkout can leave `bd_work` symlinks pointing at node paths that the new branch does not contain.

- **Current behavior:** The area is repaired only by rebuilding with `bd work REF --clean` and inspecting `bd work --status`.
- **Cost:** A stale link reads as a normal file until an edit fails or lands nowhere, and recovery is a manual two-command cycle.
- **Possible direction:** Detect the branch change on `bd work` and `--status`, then report or rebuild the affected layout in one step.
- **Constraint:** Detached edits must be preserved or explicitly discarded before repair.
