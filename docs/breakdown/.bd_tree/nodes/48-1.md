# Coverage gaps in the reference store

## Purpose

The reviewer deciding whether the committed example is sufficient evidence uses
this finding to qualify the clean result; without it, one green store is read as
covering freshness, versions, and cycles.

---

The reference store proves the happy path, not the claims that make bd_tree
distinctive. `examples/.bd_tree/nodes/` holds twelve nodes with no `freshness:`
map, so no propagating edge is exercised; there is one version per id, so
`graph-duplicate-version` cannot occur; and the component has no cycle or
back-edge. `docs/GRAPH.md:243-257` enumerates only two parents, sorted links, and
fan-in, while cycles are built in a temporary store
(`tests/test_examples.py:168-182`) and pins are built in another
(`tests/test_stale.py:12-44`). This finding assesses
(The example store is the clean reference)[[32-1, assesses]] and the limits in
(Known limits and open questions)[[47-1, assesses]]. Impact: the reference certifies topology basics and
flat layout, not freshness or version behaviour. The clean reference therefore
does not cover the two cases that make the graph distinctive.
