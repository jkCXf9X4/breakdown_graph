# One project has one writable work area

## Purpose

The agent editing a node uses this node to confirm the single writable surface;
without it, two work folders are kept side by side and their edits diverge.

---

A project has exactly one writable work area, `<project>/bd_work/`, and it holds
one view at a time; `bd work REF` replaces its contents rather than adding a
second folder (`AGENTS.md:96-105`). Every other surface is a read-only
projection or a derived render, so it cannot become a second source of truth
(`docs/DESIGN.md:28-31`). The promise is falsified by two live work folders, a
copied node file, or a hand-maintained projection edited as state. The flat
symlink layout that implements the promise is an architecture fact, not this
one; this node states only the single-writable-surface promise, and it realizes
(Large trees need a bounded agent context)[[12-1, realizes]].
