# A project root may hide its store in .bd_tree

Discovery accepts `.bd_tree/nodes` or a classic `nodes` directory, and the enclosing directory becomes the project root that owns `bd_work`.

- **Project layout:** `.bd_tree/` sits at the project root, which holds the store, the optional `ROOT` file, and `bd_work/`.
- **Classic layout:** `nodes/` sits at the repo root, and the project root is that directory.
- **Precedence:** `resolve_store_root` returns the candidate with `nodes/` first, else the candidate with `.bd_tree/nodes/` (`src/bd_tree/loader.py:72`).
- **Walk-up:** discovery walks up from the working directory recognising both layouts; `BD_ROOT` or `--root` points it at a store elsewhere.
- **One store:** a checkout holds one store, and a git worktree has its own.
- **Work area:** `<project>/bd_work/` resolves from the same detected project root in both layouts.
- **Traces to:** one project has one writable work area (21-1).
