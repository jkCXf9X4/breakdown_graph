# Ops module performs body-preserving structural edits

`ops.py` rewrites only the targeted front-matter block and appends the original body string byte for byte.

- **Init:** `init_store` writes `.bd_tree/nodes/1-1.md` with id 1 and title Root; it declares no links and no placement.
- **New:** `new_node` takes the next global id at version 1 and appends a typed link to the parent's `links`; without a parent the node starts its own component.
- **Link/unlink:** `link` appends `{to, type}` (or a scalar ref when the type matches), adds `symmetric`/`inverse`, and pins the target hash when `propagates` is set; `unlink` removes matching master edges, and their derived opposites disappear with them.
- **Versions:** `clone` copies any ref to the next free version of the same logical id (or an explicit one) and keeps the source's declared `links`, wiring nothing into the current view; with `--subtree` it clones the undirected neighbourhood of the ref (the whole component, or rings 0..N with `--depth`) and rewires each cloned parent's links to the cloned children; `replace OLD NEW` is a separate operation that repoints every inbound link (or `ROOT` when OLD is the root), leaving OLD's file as a peer; `delete` removes a node file unless it is the effective root or an inbound target of another node, with `--force` to override.
- **Body safety:** `parse_document` keeps `raw_fm` and `body`, and `rewrite_links` replaces only its own block.
- **Implements:** links define the component view (25-1).
