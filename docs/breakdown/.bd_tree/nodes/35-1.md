# Ops module performs body-preserving structural edits

`ops.py` rewrites only the targeted front-matter block and appends the original body string byte for byte.

- **Init:** `init_store` writes `.bd_tree/nodes/1-1.md` with id 1, title Root, and empty `contains`.
- **New:** `new_node` takes the next global id at version 1, appends that full ref to the parent's declared `contains`, and derives `folder` from `layer`/`group`/`type` when absent.
- **Contain/uncontain:** both edit the declared list; `contain` refuses self, cycles, and duplicates, while `uncontain` writes `contains: []` when empty.
- **Link/unlink:** `link` appends `{to, type}` and pins the target hash when `propagates` is set; `unlink` removes matching edges.
- **Versions:** `clone` copies any ref to the next free version of the same logical id (or an explicit one) and keeps the source's declared `contains`, wiring nothing into the current view; with `--subtree` it clones every containment descendant and rewires each cloned parent's `contains` to the cloned children; `replace OLD NEW` is a separate operation that finds OLD in the default view and puts NEW at OLD's exact index in its parent's `contains` (or repoints `ROOT` when OLD is the root), leaving OLD's file as a peer; `delete` removes a node file unless it is the root, reachable, or referenced, with `--force` to override.
- **Body safety:** `parse_document` keeps `raw_fm` and `body`, and `rewrite_contains` or `rewrite_links` replaces only its own block.
