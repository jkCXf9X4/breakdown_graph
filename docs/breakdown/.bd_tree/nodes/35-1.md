# Ops module performs body-preserving structural edits

`ops.py` rewrites only the targeted front-matter block and appends the original body string byte for byte.

- **Init:** `init_store` writes `.bd_tree/nodes/1-1.md` with id 1, title Root, and `band: root`; it declares no links.
- **New:** `new_node` takes the next global id at version 1, appends a typed link to the parent's `links`, and requires a band (`--band`/`--subpath` or `--layer`) or a `--stage` for placement.
- **Link/unlink:** `link` appends `{to, type}` (or a scalar ref when the type matches), adds `symmetric`/`inverse`, and pins the target hash when `propagates` is set; `unlink` removes matching master edges, and their derived opposites disappear with them.
- **Versions:** `clone` copies any ref to the next free version of the same logical id (or an explicit one) and keeps the source's declared `links`, wiring nothing into the current view; with `--subtree` it clones every structural-link descendant and rewires each cloned parent's links to the cloned children; `replace OLD NEW` is a separate operation that repoints every inbound link (or `ROOT` when OLD is the root), leaving OLD's file as a peer; `delete` removes a node file unless it is the root, reachable from the root, or referenced, with `--force` to override.
- **Body safety:** `parse_document` keeps `raw_fm` and `body`, and `rewrite_links` replaces only its own block.
- **Implements:** structural links define the view closure (25-1).
