# Ops module performs body-preserving structural edits

`ops.py` preserves the body byte for byte except for token lines and cached title prefixes, which are appended, removed, or repointed.

- **Init:** `init_store` writes `.bd_tree/nodes/1-1.md` with id 1 and title Root; it has no link tokens and no placement.
- **New:** `new_node` takes the next global id at version 1 and appends a typed token to the parent's `## Links` section; without a parent the node starts its own component.
- **Link/unlink:** `link` appends `- (TITLE)[[REF, TYPE]]` to the source's `## Links`, refuses a self-loop or a duplicate type and target, and writes `propagates`/`pinned` into the `freshness:` map; `unlink` removes matching token lines and drops the freshness entry when no token to that target remains.
- **Retitle:** `retitle` rewrites every cached title in scope (the whole store by default, or a view) from the target's live title, leaves unresolved targets untouched, and under `--dry-run` reports without writing.
- **Versions:** `clone` copies any ref to the next free version of the same logical id (or an explicit one) and keeps its tokens, wiring nothing into the current view; with `--subtree` it clones the undirected neighbourhood of the ref (the whole component, or rings 0..N with `--depth`) and rewrites cloned token refs; `replace OLD NEW` is a separate operation that repoints every inbound token (or `ROOT` when OLD is the root), sets the cached title to NEW's live title, and leaves OLD's file as a peer; `delete` removes a node file unless it is the effective root or an inbound target of another node, with `--force` to override.
- **Body safety:** `parse_document` keeps `raw_fm` and `body`; `append_token`, `remove_token`, `repoint_token`, and `retitle_tokens` touch only token lines and cached titles, and `rewrite_freshness` replaces only the `freshness:` map.
- **Implements:** links define the component view (25-1).
