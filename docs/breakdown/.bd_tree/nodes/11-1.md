# Suggested — candidates for change

This stage holds improvement candidates (`IMP-`) that are not yet selected for work. A suggestion is evidence-backed and describes a possible change without claiming it will happen, and anyone may add one. Reviewers read it when deciding which candidates are worth selecting.
