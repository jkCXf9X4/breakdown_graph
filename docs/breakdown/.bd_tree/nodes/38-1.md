# Check validates global and per-view invariants

`checker.check` loads the whole store, validates global structure, then runs the graph audit and view checks for the selected anchor.

- **Global pass:** `_check_contains_removed` covers retired `contains`; the loader reports `links-removed`, `inline-malformed`, `inline-duplicate`, and `invalid-freshness`.
- **Per-view pass:** `graph.audit` reports dangling links, orphans, fan-out, unsorted links, and duplicate reachable versions for the selected anchor; cycles are legal and never reported.
- **Selected view:** `check` validates cached token titles (`link-title-stale`), propagating pins, and body size on the resolved view; `--view` narrows that scope.
- **Size limits:** `SIZE_LINES = 120` and `SIZE_CHARS = 8000` by default, overridable with `--max-lines` and `--max-chars`.
- **Schema opt-in:** `--require FIELD` is the only front-matter validation; arbitrary fields, link types, and layers pass untouched.
- **Result:** `CheckResult` counts scanned nodes and exposes `errors`, `warnings`, and `ok`; the CLI returns 1 when `ok` is false.
- **Verifies:** links define the component view (25-1).
