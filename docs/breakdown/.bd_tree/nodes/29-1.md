# Root precedence selects the default view

An explicit ref wins over the `ROOT` file, which wins over the lowest available node by `(id, version)`, and the default root is independent of the view in the work area.

- **Precedence:** an explicit ref or a command's `--view REF`, then store `ROOT`, then the lowest available node by `(id, version)`.
- **ROOT file:** one ref on one line and nothing else; `bd root REF` writes it and `bd root --clear` removes it.
- **Errors:** a declared but missing ref is `root-ref-missing`, and malformed content is `invalid-root`.
- **Default use:** `bd work` with no REF uses the default view, and `bd views` marks the store default with `*`.
- **Independence:** `bd root` changes the default commands start from, while only `bd work REF` changes what `bd_work/` holds.
- **Report:** `bd root` prints `<ref>  (ROOT|lowest node)`.
- **Traces to:** large trees need a bounded agent context (17-1).
