# Temporary stores drive the test suite

`tests/` writes real node files under pytest's `tmp_path` and asserts both loaded values and exact file bytes.

- **Fixture:** `tests/conftest.py` exposes `write_node`, which renders front matter and derives `home` from `layer` when `home` is absent.
- **Real loader:** tests call `load`, `load_view`, `check`, and `main` against temporary directories instead of mocking the loader.
- **Byte assertions:** structural tests compare body text before and after edits; one `test_structure.py` case covers every structural edit.
- **Layouts:** tests cover classic `nodes/` and project `.bd_tree/nodes/` stores, including the `project_root` mapping.
- **Speed:** the suite uses no network and runs in seconds with `python3 -m pytest -q`.
