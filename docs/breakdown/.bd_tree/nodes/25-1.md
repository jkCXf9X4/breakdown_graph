# Structural links define the component view

`links` is the one edge relation: a view is the whole undirected component around one ref, and distance rings order nodes inside it.

- **Membership:** `load_view` walks `Store.neighbors` (authored links in both directions) from the ref and includes each node once, so multiple parents and cycles are legal (`src/bd_tree/loader.py:603`).
- **Order:** link list order is not display order; the work layout sorts each ring by distance, kind, link type, id, and version, and `bd link` keeps targets sorted by ref for stable data.
- **No inheritance:** `links` are authored per file; `bd clone` copies the source bytes, `bd clone --subtree` follows undirected neighbours (the whole component, or rings 0..N with `--depth`) then rewires each cloned parent's links to the cloned children, and `bd replace OLD NEW` repoints every inbound link (or `ROOT`) while the old file stays a peer.
- **Cycles:** a repeated ref closes the walk instead of failing; cycles are legal, and two reachable versions of one id still warn `graph-duplicate-version`.
- **Symmetric links:** one node authors a symmetric master; the opposite is derived at load, marked `[derived]`, never written, and joins the two nodes as peers in the undirected component.
- **Reachability:** every disconnected component has one representative root; `bd views` lists them and nodes outside the anchor's component warn `graph-orphan`.
- **Traces to:** one store yields many read-only projections (22-1).
