# Contains is ordered closure data

`contains` is an ordered ref list per node, and a view is the closure reached by walking that list from one root.

- **Order:** list order is display order; the exporter and browser never re-sort it.
- **Closure:** `load_view` walks declared `contains` from the ref and returns the included nodes plus internal edges (`src/bd_tree/loader.py:609`).
- **No inheritance:** a version that omits `contains` is a leaf (`[]`), and `bd clone` copies the source file, so the copy keeps its declared list; `bd clone --subtree` instead rewrites each cloned parent's `contains` to the cloned children, and `bd replace OLD NEW` wires a clone into the default view at the old ref's exact index, or repoints `ROOT` when the old ref is the store root.
- **Tree rule:** one view cannot reach a node through two parents; the walk reports `multiple-parents`.
- **Cycle:** a ref repeated on the walk path is a `containment-cycle` error.
- **Global reachability:** every ref is reachable from the root, through another file with the same id, or through an outgoing link from a reachable node; else it is `unreachable`.
