# Exporter renders read-only projections

## Purpose

The agent assembling task context uses this node to trust pack output as a
projection rather than a second editable area; without it, a stale or
overwritten snapshot is read as store state.

---

`exporter.export_context` materializes one `View` into a disposable directory:
included nodes, `STALE.md`, and a generated `AGENTS.md`; stale bodies are
deliberately excluded (`src/bd_tree/exporter.py:319-395`). `_prepare_out`
refuses a non-empty target unless the caller passes `force` or `clean`, and
`_write_node` copies the parsed meta and body through `render_document` without
consulting the store again (`src/bd_tree/exporter.py:24-38`, `77-81`). The same
rule covers `graph.export_graph` and the DOT/SVG renderers: they read the
anchored graph and write elsewhere, never the store. This module implements
(One store yields many read-only projections)[[17-1, implements]]. The invariant
is that a projection is never a second work area; failure is an in-place pack
that overwrites unrelated files or a stale body presented as current context.
