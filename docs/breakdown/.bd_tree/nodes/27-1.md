# Links form a DAG outside view membership

Typed links express semantics and never add a node to a view; a target in the store but outside the closure is external unless it roots another view.

- **Shape:** `links` is a list of scalar full refs or `{to, type, propagates?, pinned?}` objects that may cross subtrees as a DAG.
- **Scalar link:** `links: ['10-1']` takes its type from node `10-1`'s `type`; a target without one is `invalid-link` (`src/bd_tree/loader.py:391`).
- **Membership:** only `contains` decides view membership; a link never pulls its target in.
- **Reachability:** an outgoing link from a reachable node keeps its target reachable, so a linked history view is not `unreachable` (`src/bd_tree/checker.py:145`).
- **External target:** a link to a node outside the view is dropped from the view's edges; it warns unless the target is itself a containment root (`src/bd_tree/loader.py:487`).
- **Dangling target:** a link to a ref absent from the store is an error, not a warning.
- **Freshness:** `propagates: true` opts this edge into staleness, and `pinned` holds the target body hash from the last reconciliation.
- **Traces to:** credibility belongs to the producing chain (16-1).
