# Links are the one typed topology

Typed body tokens are the only edge relation. Every token connects its two nodes in the undirected view; a back-reference is a second authored token, not a derived opposite.

- **Shape:** `(TITLE)[[REF, TYPE]]`, with the cached title as a prefix and optional spaces between `)` and `[[`; a bare `[[REF, TYPE]]` is valid. Written inline in prose or as a `- (TITLE)[[REF, TYPE]]` line in a trailing `## Links` section. `REF` comes first and is a full `id-version`; `TYPE` comes second and is an arbitrary label matching `[A-Za-z][A-Za-z0-9_-]*`; `TITLE` is non-empty and excludes `)` and newlines.
- **Retired shape:** front-matter `links`, scalar links, and implicit types are gone; a node that still declares `links` is `links-removed` (`src/bd_tree/loader.py`).
- **Scanner:** fenced code blocks, inline code spans, and `\[[` escapes are ignored; indented code blocks and HTML comments are not. A malformed fragment is `inline-malformed`, and a repeated type and target on one node warns `inline-duplicate`.
- **Cached title:** `(TITLE)` is tool-generated from the target's live title and is never hand-edited; rendering reads the live title, `bd check` warns `inline-title-missing` or `link-title-stale`, and `bd retitle` regenerates it.
- **Writers:** `bd new --parent`, `bd link`, and `bd migrate` append token lines, `bd unlink` removes them, `bd retitle` refreshes titles, `bd replace` rewrites inbound refs with the new title, and `bd clone --subtree` rewrites refs in place.
- **Membership:** authored tokens in either direction define the component and the shortest `bd path`; `Store.components` derives one representative per component (`src/bd_tree/model.py`).
- **Dangling target:** a token to a ref absent from the store is `graph-dangling-link`, an error (`src/bd_tree/graph.py`).
- **Freshness:** the source node's top-level `freshness:` map, keyed by target ref, carries `propagates` and `pinned`; the pinned hash ignores token lines and the `## Links` heading.
- **Traces to:** credibility belongs to the producing chain (16-1).
