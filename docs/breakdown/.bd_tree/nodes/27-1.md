# Links are the one typed topology

`links` is the only edge relation. A structural link expands the view and orders bands; a symmetric master states a relation and derives its opposite without doing either.

- **Shape:** `links` is a list of scalar full refs or `{to, type, propagates?, pinned?, symmetric?, inverse?}` objects, kept sorted by target ref.
- **Scalar link:** `links: ['10-1']` takes its type from node `10-1`'s `type`; a target without one is `invalid-link` (`src/bd_tree/loader.py:545`).
- **Membership:** only authored non-symmetric links expand a view and define `bd path` ancestry, topology roots, and band inference (`src/bd_tree/model.py:232`).
- **Symmetric master:** `symmetric: true` with an optional `inverse` type is authored by exactly one node; `bd out` and `bd show --links` mark the derived opposite `[derived]`, and the opposite is never stored.
- **Dangling target:** a link to a ref absent from the store is `graph-dangling-link`, an error, even for a symmetric master (`src/bd_tree/graph.py:1416`).
- **Freshness:** `propagates: true` opts a structural edge into staleness, and `pinned` holds the target body hash; `propagates` is invalid on a symmetric link.
- **Traces to:** credibility belongs to the producing chain (16-1).
