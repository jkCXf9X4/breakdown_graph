# Init scaffolds a hidden-store project

## Purpose

The operator starting a new project uses this claim to get a valid store without hand-writing files; without it, a missing root node or `.gitignore` entry makes every later command fail or leak the work area into git.

---

`bd init [DIR]` writes the project layout: `.bd_tree/nodes/1-1.md` as an unlinked graph root, plus a `.gitignore` entry for `bd_work/` (`README.md:132-163`, `docs/GETTING-STARTED.md:246-288`). Init operates the identity rule in (A filename encodes identity and version)[[18-1, operates]]: the root is named `1-1.md` before any command can address it (`src/bd_tree/ops.py:159-181`). It refuses a directory whose `.bd_tree/nodes` or `nodes` is non-empty rather than merging into an existing store (`src/bd_tree/ops.py:159-181`). The failure is a hand-built root or a missing ignore line: `bd new` cannot allocate against a malformed root, and `bd_work/` appears in every `git status` until ignored (`docs/GETTING-STARTED.md:481-506`).
