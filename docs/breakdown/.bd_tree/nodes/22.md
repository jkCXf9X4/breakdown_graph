# One store yields many read-only projections

The node files under `nodes/` are the only truth; views, exports, graphs, and the work layout are reproducible projections of them.

- **Truth:** a store is a flat directory of `<ref>.md` node files, and no other file is authoritative.
- **Projections:** `bd view REF --out DIR` renders the tree, `bd export context` emits fresh nodes plus `STALE.md`, and `bd export dot` emits Graphviz.
- **Disposable:** derived output is gitignored and may be rebuilt at any time from the store.
- **Multiplicity:** read-only projections may be many because none of them is writable.
- **Single writable surface:** only `<project>/bd_work/` accepts edits, and it holds one view.
- **No sidecar:** no JSON, TOML, lock, or state file; the one store-level pointer is `ROOT`, a single ref line.
