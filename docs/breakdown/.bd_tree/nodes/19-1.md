# Front matter stays project-defined

Only a few structural keys are built in, so layers, edge types, and status values remain data the project defines.

- **Reserved keys:** `id`, `legacy`, and `freshness`; link declarations are body tokens, not front matter, and authored placement is retired, so `band`, `subpath`, `layer`, `stage`, and `order` are ordinary fields that place nothing; every other field is arbitrary and preserved on export.
- **Fields:** `phase`, `audience`, `status`, and `group` are ordinary fields that the tool never interprets.
- **Edge types:** a token `TYPE` is an arbitrary label matching the token grammar, never validated against an enum.
- **Opt-in schema:** `bd check --require FIELD` is the escape hatch when a project wants a required field.
- **Presentation:** path templates read any front-matter field, and dot styling selects by `--color-by` and `--shape-by`.
- **Traces to:** credibility belongs to the producing chain (16-1).
