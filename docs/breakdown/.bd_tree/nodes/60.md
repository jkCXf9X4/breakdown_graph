# Decisions stay in the store, linked out of the default view

- **Context:** Decision records are history that explains current state, but a separate archive makes them harder to reach than necessary.
- **Decision:** Keep decisions in the store as their own containment view. Root 1 links with `links: ['10']`; node 10 declares `type: decision`; root 1 does not contain it.
- **Rationale:** `contains` still decides view membership, so the default work area stays current-state only. The bare link keeps the records reachable and `bd check` clean.
- **Alternative:** A `soft-contains` key was rejected: it adds schema. The bare ref plus the target's `type` keeps the edge compact without one.
- **Consequences:** `bd views` lists the Decisions view; `bd show 1 --links` points to it; editing needs `bd work 10`.
