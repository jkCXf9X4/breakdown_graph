# Node files are the only source of truth

## Purpose

The editor deciding where a change belongs uses this claim to choose the node
file over any derived artifact; without it, an edit lands in a projection and
disappears at the next rebuild.

---

The node files are the only authored data; every other artifact is computed and
disposable: views, indexes, graphs, packs, and the work layout are derived from
`nodes/` or `.bd_tree/nodes/` (`AGENTS.md:49-50`, `docs/DESIGN.md:28-31`). No
layout state is stored; components, distances, ring sections, and the area are
recomputed on every command (`docs/GRAPH-LAYOUT.md:13-26`). No sidecar holds
state: the only pointers are `ROOT` (one ref) and `.bd_root` (one store path),
and the active area view lives in generated `REFS.md` (`AGENTS.md:103-105`,
`112-117`). Because every projection is derived, one store yields many read-only
slices, so the claim realizes
(One store yields many read-only projections)[[17-1, realizes]]. It is
falsified when deleting derived output loses a fact or a derived file changes
what another checkout reads.
