# Model and checker separate shape from validation

`model.py` defines the containers and `checker.py` inspects a freshly loaded store without mutating it.

- **Model types:** `Node`, `Link`, `Store`, `View`, `Edge`, and `Issue`; `Store.structural_links` returns authored tokens, `graph.build_graph` derives `inn` by reversing them, and `View` holds the component with its distance rings.
- **Issues as data:** the loader records `Issue(level, code, message, node, path)`, and `CheckResult.ok` is true when no error remains.
- **Checker scope:** filename grammar, bare refs, id mismatch, duplicate refs, `contains-removed`, `links-removed`, `inline-malformed`, `inline-duplicate`, `inline-title-missing`, `link-title-stale`, `invalid-freshness`, dangling links, orphans, fan-out, unsorted links, duplicate reachable versions, freshness, and size.
- **Independent pass:** `check()` calls `load` again, so it validates the files instead of trusting an edited in-memory graph.
- **Opt-in schema:** `--require FIELD` is the only front-matter validation; arbitrary keys, link types, and layer names pass untouched.
- **Implements:** links define the component view (25-1).
