# Evolution — what might change

This is the work layer, not a claim layer: it holds open work and never restates current state. The improvement funnel runs `suggested/` → `selected/` → `implemented/`, while `investigations/` holds open design-space questions and `plans/` holds one task contract per selected improvement. Authors and reviewers read it to see what is being considered, what must be learned, and how accepted work will be done.

Start at `INDEX.md` and open the one leaf that owns the question you have.
