# Discovery walks up to nodes or .bd_tree

`cli._find_root` checks the current directory and each parent for `nodes/` and `.bd_tree/nodes/`, then resolves the winner.

- **Precedence:** an explicit `--root` wins, then `BD_ROOT`, then the ancestor walk.
- **Layouts:** the walk recognises both `nodes/` and `.bd_tree/nodes/`; `resolve_store_root` prefers classic `nodes/` when a candidate has both.
- **Result:** the walk returns a store root, and a project root handed to `load` or `--root` is reduced to `.bd_tree` by `resolve_store_root`.
- **Descendants:** a command run in a nested directory finds the nearest ancestor store.
- **Fallback:** with no store found, `_find_root` returns the current directory and the loader reports `missing-nodes-dir`.
