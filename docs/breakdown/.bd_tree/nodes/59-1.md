# Flat view index grouped by ring

The work area is flat, so `bd work` writes only one generated `INDEX.md` at the area root.

- **Current behavior:** `INDEX.md` lists the whole component as one ring-sectioned file; a distance ring has no index of its own.
- **Cost:** A large component still reads from one long root file, and a reader who starts at a distant ring has to scroll the root file to orient.
- **Possible direction:** Emit a generated `INDEX.md` per distance ring, covering only that ring and its links.
- **Constraint:** Generated index names are reserved paths; a node path may not claim `INDEX.md`, and an index must stay derived and disposable.
- **Changes:** links define the component view (25-1).
