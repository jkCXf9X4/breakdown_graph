# Per-folder view indexes

A layered view places nodes in folders, but `bd work` writes only one generated `INDEX.md` at the area root.

- **Current behavior:** `INDEX.md` lists the whole view as one nested outline; a folder has no index of its own.
- **Cost:** A large layer still reads from one long root file, and a reader who starts inside `02-architecture/` has to walk back up to orient.
- **Possible direction:** Emit a generated `INDEX.md` in every directory that holds nodes, covering only that directory and its descendants.
- **Constraint:** Generated index names are reserved paths; a node path may not claim `INDEX.md`, and an index must stay derived and disposable.
