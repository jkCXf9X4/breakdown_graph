# Loader owns filenames, discovery, and views

`loader.py` turns `nodes/*.md` filenames into refs and resolves both the store root and one containment closure.

- **Filename grammar:** `FILENAME` and `REF` accept `<id>.md` or `<id>-<version>.md` with positive integers and no leading zeros; version 0 is main.
- **Store resolution:** `resolve_store_root` accepts a project root or a store root and prefers classic `nodes/` over `.bd_tree/nodes/`.
- **ROOT:** `_read_declared_root` reads one ref from `<store>/ROOT`; `Store.root_ref` returns it before the lowest main ref.
- **View closure:** `load_view` walks `effective_contains` and reports `multiple-parents`, `containment-cycle`, `missing-target`, and `external-link` unless the target roots another view.
- **Implicit link type:** after all files load, a bare link takes the target's `type`; a target without one is `invalid-link` (`src/bd_tree/loader.py:391`).
- **Discovery boundary:** `cli._find_root` walks ancestors and calls `loader.resolve_store_root`, while `load` also accepts either root directly.
