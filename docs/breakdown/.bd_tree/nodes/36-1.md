# Solutions module wraps git worktree

`solutions.py` runs three `git worktree` queries and keeps no branch or path record of its own.

- **Create:** `new` resolves the repository and store, then runs `git worktree add <path> -b <name>` or checks out an existing branch.
- **List:** `listing` parses `git worktree list --porcelain` and marks the primary worktree and checkouts that contain the store.
- **Remove:** `remove` matches a branch or path, refuses the primary worktree, runs `git worktree remove`, and keeps the branch.
- **State:** the module stores no list; each `SolutionEntry` is rebuilt from git output on every call.
- **Projection:** `new` returns the project directory inside the worktree and the store default view for the printed `bd work` command.
- **Implements:** git owns the solution boundary (20-1).
