# Discovery walks up, then scans down for a unique store

`cli._find_root` checks the current directory and each parent for a store (`nodes/` or `.bd_tree/nodes/`) and a `.bd_root` pointer, then resolves the winner. If the upward walk finds nothing, it calls `loader.stores_below` for a bounded downward fallback.

- **Precedence:** an explicit `--root` wins, then `BD_ROOT`, then the ancestor walk, then the downward scan. At each ancestor level a store in that directory wins over a `.bd_root` there. An upward match always beats a downward one.
- **Folder-level `.bd_root`:** any directory may hold a `.bd_root` file with one store path line, absolute or relative to that directory. It names the store a working folder belongs to, which disambiguates several stores below cwd. `loader.root_pointer_at` validates it; empty, multi-line, or non-store content is `invalid-bd-root:`. It is separate from the store-level `ROOT`, which names a default view ref.
- **Layouts:** both walks recognise `nodes/` and `.bd_tree/nodes/`; a candidate normalizes to `candidate.resolve()` for classic and `<candidate>/.bd_tree` resolved for project layout. `resolve_store_root` prefers classic `nodes/` when a candidate has both.
- **Downward scan:** strictly below cwd, at most depth 3, sorted for determinism, symlinks not followed, and heavy or irrelevant directories pruned (`.git`, `node_modules`, `.venv`, `venv`, `__pycache__`, `bd_work`, caches, build output).
- **Several stores below cwd:** discovery raises `BreakdownError` listing every resolved store path sorted, with a hint to choose via `--root PATH` or `BD_ROOT=PATH`; it never silently picks one.
- **One store below cwd:** discovery uses it and prints a one-line notice on stderr, leaving stdout clean.
- **No store:** discovery raises an explicit `BreakdownError` naming cwd, the failed upward walk, the depth-3 downward scan, and the `--root`/`BD_ROOT` remedies.
- **Check exception:** `bd check` asks discovery to allow a missing store, so it keeps its `missing-nodes-dir` diagnostic and exit code instead of a discovery error.
- **Descendants:** a command run in a nested directory finds the nearest ancestor store first; the downward fallback only applies when no ancestor qualifies.
- **Operates:** a project root may hide its store in .bd_tree (24-1).
