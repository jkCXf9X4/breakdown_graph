# Decisions — why bd_tree changed

## Purpose

The engineer or agent deciding where a change's rationale belongs uses this
index to reach the decision log; without it, history is looked for in the state
layers and a record is read as current truth.

---

The decision layer records why a baseline changed. A record is history: it points
at the leaves that now hold the outcome, and a live leaf never cites it
(`../../src/agent_methods/methods/product-breakdown/guidelines/history-rules.md:3-38`).
The index routes to the record and does not restate its argument.

Its single member is (Decisions live in the store as history)[[49-1, breaks_down]], the one record the index routes to.

The index is current only while every record it lists resolves to a live file; a
missing record is a repair, not a broken link, while a superseded record stays as
history
(`../../src/agent_methods/methods/product-breakdown/guidelines/history-rules.md:35-37`).
