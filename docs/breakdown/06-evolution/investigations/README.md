# Investigations — open design-space questions

This folder holds investigations into open questions that are not yet improvement candidates. Each topic gets its own folder with its own `README.md` and `INDEX.md`, and each investigation is a single leaf carrying the question, findings, and result. Anyone facing an unresolved design question reads the topic that matches it before proposing a change.

Start at `INDEX.md` and open the one leaf that owns the question you have.
