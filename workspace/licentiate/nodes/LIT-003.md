# How do the NASA credibility frameworks treat intended use?

The NASA-standard family is the thesis's closest prior art, so what it does and does not define is load-bearing.

- **Requirement:** NASA-STD-7009 requires "intended use" to be defined for M&S products and assesses the appropriateness of the simulation relative to its intended use (`blattnigNASAStandardModels2013`).
- **No definition:** neither the standard summary nor the CAS defines intended use or decomposes it into checkable structure (`blattnigNASAStandardModels2013`, `babulaNASAStandardModels2009`).
- **Proxy:** the formally defined bounded-applicability concept is "limits of operation", the boundary of the parameter set for which an M&S result is acceptable (`blattnigNASAStandardModels2013`).
- **Verification:** quotes verified against the pinned library's extracted text in the 2026-11 intended-use audit (`review-2026-11/source-audits/intended_use_domain_cluster.md`).
- **Serves:** the definition clause's novelty (`ARG-006`), the framework table (`MS-003`), and the framework-cell work (`IMP-018`).
