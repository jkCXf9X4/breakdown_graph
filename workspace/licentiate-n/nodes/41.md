# Sub-question decomposition

Four sub-questions decompose the primary question (`34`), each of the last three acting on one kind of M&S metadata.

- **SQ1, premise:** What credibility, traceability and collaboration challenges do practitioners report across simulation domains, and to what extent do standardized interfaces address them? Paper I; adds no property.
- **SQ2, intended use explicit:** How can intended use be defined from requirement verification evidence and exchanged as standardized, machine-interoperable metadata carried alongside the model definition, so that a model's operational domain travels with the model and a result's claim is explicit about the decision it supports and the conditions under which it holds? Paper II; answers the intended-use clause (`94`).
- **SQ3, evidence auditable:** How can model verification workflows be automated and versioned as standardized, machine-interoperable records, so that verification evidence is auditable: traceable to the workflow, inputs and versions that produced it, repeatable, and comprehensible? Paper III; answers the evidence clause (`94`).
- **SQ4, definition traceable:** How can an authoritative system architecture generate standardized system definitions, and how can downstream edits be synchronized back without losing that authority, so that the executed composition remains traceable to the architecture that defines it? Paper IV; answers the definition clause (`94`).
- Each sub-question has exactly one appended paper, and each contract clause one answering sub-question.
- Append order follows the papers, not chronology (`35`).
- Where each sub-question is argued in the kappa is `116`.
