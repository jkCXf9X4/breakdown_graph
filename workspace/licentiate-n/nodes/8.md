# Set the appendix page budget

Papers I-IV enter the appendix as LaTeX bodies set in the thesis type, two columns at `\small` (`38`, `20`).
The four-paper build produces 184 pages and 5492446 bytes at the recorded pins (`51:13`).
The earlier measurement described a six-paper book: 56 appendix pages over 40 facsimile pages, closing at 193.
The growth is typography, not content: a narrower measure and larger leading applied to bodies written for two-column or other sizes.
`29` states format, length, and authorship obligations but no page ceiling, so the budget is a judgement about examiner expectation, not a rule check.
**Evidence:**

An appendix that grows the imported papers competes with the kappa narrative for the examiner's attention.
The page cost was measured once, for a book that no longer exists, so the current book has no recorded budget.

- `51:13` records 184 pages and 5492446 bytes for the four-paper book.
- `38:16` records the two-column `\small` setting the page count follows from.
- `51:22` records the three tolerated overfull hboxes.
- `29:14-19` lists the examiner's obligations and names no page bound.
**Acceptance:**

Two options; the smaller-size one is taken, the accept-as-is one stays open.

- Accept the thesis typography as is. Does a 184-page document meet faculty format rules and examiner expectations? Done when the answer is recorded and `51` keeps 184 as its reference page count.
- Set the imported bodies at a smaller size. The papers already run two-column at `\small` (`38`); reclaiming more pages would need a smaller size still.
- Either way `51` carries the resulting page count, the per-paper split, and the overfull tolerance.

- Redoing the migration for content reasons; the bodies are landed and compile (`21`).
- Restyling the paper figures beyond the house-style widths already applied (`38`).
