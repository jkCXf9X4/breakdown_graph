# Re-derive the gap claim against the four frameworks' own text

`03_background` locates the contribution in two sentences.
The first says no framework "treats execution as more than numerical error" (`thesis/chapters/03_background.tex:53`).
The second says "intended use is assessed by all four" (`thesis/chapters/03_background.tex:76`).
Both are readings of `tab:framework-coverage` (`thesis/chapters/03_background.tex:69`), and both are contradicted by the sources the table cites.
The same gap claim is restated in the gap analysis as "a composition that can drift from its defining architecture" (`thesis/chapters/04_research_questions_and_contributions.tex:9`), attributed to two sources that contain neither word.
**Evidence:**

These two sentences are the thesis's novelty claim. If either is false, the contribution is unsupported at the point it is made.
The first is false for two of the four frameworks on their own text, so an examiner who knows the frameworks can refute the claim from the sources the thesis itself cites.
The second contradicts the table printed 7 lines above it, which marks the PCMM row `Use = part`.
The half of the gap argument that does survive is the `Def. = no` column, and the thesis under-cites it: the strongest warrant is a positive statement of the integration gap by the framework's own authors, and it is not quoted.

- `thesis/chapters/03_background.tex:53` asserts no framework treats execution as more than numerical error.
- `blattnigCredibilityAssessmentModels2008` text.md L204-206 defines code verification as software quality assurance: version control, configuration management, documentation, regression testing. That is an execution concern and it is not numerical error.
- `royComprehensiveFrameworkVerification2011` text.md L170 includes "errors due to computer programming mistakes" in verification.
- `thesis/chapters/03_background.tex:67` marks the Rigor Scale row `Exec. = no` while the scale has a first-class code verification category.
- `thesis/chapters/03_background.tex:76` asserts intended use is assessed by all four; the same table marks PCMM `Use = part`.
- `blattnigNASAStandardModels2013` text.md L530-532 says the NASA scale separates requirements from the assessment process, which contradicts "assessed by all four" for the CAS.
- `royComprehensiveFrameworkVerification2011` has zero occurrences of "intended" in 1,124 lines.
- `babulaNASAStandardModels2009` text.md L447-451 carries a NESC recommendation that the standard "makes no distinction between individual models and integrated models" and that assessment "should eventually be refined to account for the additional issues associated with integration of submodels". This is a positive statement of the gap and it is not cited.
- `thesis/chapters/04_research_questions_and_contributions.tex:9` attributes "drift" and "architect" to `gomesCoSimulationSurvey2018` and `rosenlundRoleStandardizationSimulation2025`; both words return zero hits in both files.
- Review record `128`; audit: `.dynamic-harness/261101_082500_e339/review/claims-intro-bg.md` BLOCKER 1 and BLOCKER 2; `.dynamic-harness/261101_082500_e339/review/claims-rq-methods.md` F-03.
- `112` owns the positive statement of the integration gap the narrowed claim will rest on.
**Acceptance:**

- The gap claim is one sentence that survives all four frameworks' own text, or the table is changed to match the sentence.
- Every framework named in a negative claim has a quoted sentence in the library that supports it, or is removed from the claim.
- The CAS cell cites `babulaNASAStandardModels2009` L447-451 as a positive statement of the integration gap.
- `03_background.tex:76` either drops "all four" or the `Use` column is corrected to agree with it.
- `04_research_questions_and_contributions.tex:9`'s drift clause carries a citekey whose text contains the claim, or is marked as the thesis's own construction.
- The narrowed claim still carries the contribution: the definition clause remains the one no framework assesses.
**Out of scope:**

- The cells themselves, which `97` owns; this leaf owns the two sentences that read the table.
- Whether the contract is derived or stipulated (`77`).
- The uncited claims elsewhere in ch02 and ch03 (`111`).
