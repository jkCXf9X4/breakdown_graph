# When is the kappa reviewed?

Review is a gate, not an event; it runs at three triggers.

- **Per change:** when nodes are touched, the owning layer's gates rerun, and a reviewer checks the touched subtree against `30`.
- **Per release:** before `pb registers` regenerates the release surfaces, a full-kappa sweep runs against `30` and the requirement map `14`.
- **On layer-model change:** a migration that redefines the layers triggers a full sweep, because every leaf's owning layer can shift.
- **Gate relation:** a full sweep is also the manual pass that `28` has no check for (`14` calls the missing reader pass out).
- **Cadence practice:** the 2026-11 run was a full sweep; its record is `32`.
