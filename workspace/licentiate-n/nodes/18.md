# Reference intake workflow

The library is a papis library pinned at `3rd_party/references`. `thesis/references.bib` is rendered from it by `refs subset`.

**Add a source:**

- Put the PDF in the library intake queue `new/`.
- Run `refs intake --library 3rd_party/references` for a report.
- Run `refs intake --library 3rd_party/references --apply` to write the document.
- Commit the new document in the `3rd_party/references` repo.
- Bump the library pointer here; see `25`.

**Register the citekey:**

- Add the citekey to `thesis/references.yml`.
- Run `./thesis/references.sh update`.
- Run `./thesis/references.sh check`.
- `check` fails when `references.bib` is stale, or a cited key is missing from the yml.

**Rules:**

- Never hand-edit `thesis/references.bib`; it is generated.
- Never rewrite an existing citekey; keys are the stable interface.
- Never open a PDF; use `refs text` or `refs search` for content.
- After a library metadata edit, run `rm -rf ~/.cache/papis/database`.
- Without the cache drop, the exporter serves the old record.
- Included-paper entries stay in hand-kept `thesis/papers.bib` (`22`).

**Text adequacy:**

An extracted `text.md` is adequate only if it covers the document's body. A clean extraction of the wrong pages passes every metadata flag, so check the two signals that are not flags (`125`):

- **Extent.** `text_pages` is at least half the document's real extent. Real extent is `numPages` when the record declares it, otherwise the highest page number in a table-of-contents entry in the first half of `text.md`, ignoring four-digit numbers in 1900-2100, which are years and not pages.
- **Body heading.** `content.md` holds at least one heading that is not front matter: after stripping a leading roman-numeral page prefix, the heading is not one of contents, preface, foreword, acknowledgements, list of figures or tables, abstract, index, bibliography, or the document's own title, and it carries at least two words.

`text_poor`, `ocr_needed` and `text_order_score` measure the text layer's quality, not its scope, and cannot detect this. Neither can `refs lint --text-quality`. The check is prose-only: no tool computes it, so it is run by hand at intake and recorded in the document's `note:` field when it fails.
